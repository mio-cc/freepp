## 依赖关系

### 后端
- `app.py` → 所有 `api/*` 路由 + `core/config` + `core/secrets_store` + `core/auth_store`(新) + `core/session`(新)
- `api/auth.py`(新) → `core/auth_store` + `core/session`
- `api/config.py` → `core/config` + `core/secrets_store`
- `core/auth_store.py`(新) → 无（纯标准库 hashlib/secrets/json/os）
- `core/session.py`(新) → `core/auth_store`（取 session_secret）

### 前端
- `App.tsx` → `store/useStore`（auth state）+ `views/LoginView`(新) + 其他 views
- `api/client.ts` → `store/useStore`（401 时触发 logout）
- `views/LoginView.tsx`(新) → `store/useStore` + `api/client`
- `views/SecretsView.tsx` → `api/client` + `store/useStore`
- `components/layout/Sidebar.tsx` → `store/useStore`（logout）
